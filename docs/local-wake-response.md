# 本地唤醒回应

ESP32-S31-Korvo-1 默认启用 `CONFIG_LOCAL_WAKE_ACK`，检测到“你好小满”后播放固件内的“我在”，并建立语音连接。回应开始播放无需等待服务器；连接完成后才能上传用户语音。该模式不发送唤醒词录音或 `listen/detect`，避免服务器另行生成欢迎语。

音频：`main/assets/common/wake_ack.ogg`，文本“我在。”，使用现有小满配置的 CosyVoice `cosyvoice-v3-flash` / `longyumi_v3` 音色一次性生成，移除首尾静音并保留 80 ms 尾音余量。16 kHz 单声道 Opus，60 ms 帧，24 kbit/s，约 0.42 秒、1.3 KB。运行时完全本地播放，不携带 TTS 凭据。

播报期间保持 AFE 唤醒检测，包括实时聆听模式。识别到唤醒词后先取消本地解码和播放队列，再通知服务器取消；已取消轮次的后续音频会被丢弃。“我在”播放完成后开启语音上传，避免回应被重置截断或作为用户语音上传。

验证需覆盖：待机首次唤醒、长回答中唤醒打断、连续打断、聆听中再次唤醒、连接失败时仍有本地回应、按键唤醒和正常对话。主机回归测试运行实际 Application 方法并替换音频和网络依赖；物理识别率与主观音色需在设备上验证。

AFE 状态切换仅提交重置请求，避免主线程等待正在执行 feed 的输入锁。前端任务通过 try-lock 执行重置；锁忙时继续消费并丢弃旧音频，腾出缓冲后再重置，防止生产者和消费者互相等待。

2026-09-24：S31 编译和 86 项主机测试通过；修复版烧录后，用户确认连续对话和中途唤醒打断正常，界面未再次卡住。断网、其他板型及长时间压力测试仍待验证。
